# 26_SCARP_EduVideo

An AI-driven system that automatically converts written computer science learning materials — lecture slides, notes, lab handouts, and example code — into short, engaging teaching videos.

## Motivation

CS courses like CS I, data structures, and algorithms rely heavily on written materials. While informative, students often find short explanatory videos more engaging and easier to follow, especially for abstract topics like recursion, data structures, and algorithms. Creating these videos manually is time-intensive for instructors and hard to scale.

## Goal

Explore how AI can transform existing course documents into dynamic video learning resources — not to replace instructors, but to help scale their reach and support student understanding.
